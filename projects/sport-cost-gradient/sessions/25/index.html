Session 25: Pipeline Divergence and v1.00 Data Preparation

Summary#

Reproducibility test 2 (an independent Claude session given the corrected v0.99.4 redacted paper with country-clustered SEs) produced results close but not matching: primary β = −0.698 (paper: −0.65), p = 0.032 (paper: 0.016), n = 1,882 (paper: 1,944). The gender decomposition hit sport name mapping bugs, and population elasticity required a log-log model form not obvious from the paper text.

Rather than patching the paper with reproducibility numbers (an approach briefly attempted and then reverted), the decision was to trace the root cause. An exploration of the original pipeline (v0_99_game_level_pipeline.py) versus the reproducibility script revealed three divergence points in sample construction: (1) GDP median calculated from different sources (two-period average from predictors_master.json vs game-level GDP after positive-points filtering), (2) positive-points filter applied at different stages, (3) >= vs > median threshold producing 36 vs 35 upper-GDP countries. These cascade into different regression samples and different coefficients throughout.

Two structural improvements were made to the paper text and kept: Section 8.5 gained a paragraph explaining why a log-log model is needed for population elasticity (the elasticity α is only interpretable as a comparison to unity in log form), and Section 7.7 gained a note that gender decomposition uses pre-aggregated gender-specific data with sport name harmonisation.

A GDP median split definition was agreed for v1.00: compute each country’s mean GDP per capita across all games, rank once (time-invariant), use >= median. This will be stated explicitly in the paper methodology.

The session then created the v1.00 data folder — all v0.99 data copied and renamed, plus a gender enrichment script that adds points_men, points_women, and points_mixed columns to the main panel. The enrichment required matching the original panel builder’s logic for athletics track/field classification (decathlon/heptathlon → Track, not Field), NOC remapping (EUN→RUS, TCH→CZE, ROC→RUS), AIN athlete-level mapping (Paris 2024 neutral athletes to RUS/BLR), and 3x3 Basketball → Basketball. All 69 “Unknown” gender events were resolved by parsing the event name. Final validation: all 26,199 panel rows pass points_men + points_women + points_mixed == points with zero mismatches.

Version: v0.99.4 → v1.00 data preparation

Claude: Picking up on the GDP definition question.

There are three dimensions to the “upper half GDP” definition that diverged between the original pipeline and the repro test:

1. What GDP value to use for ranking

The original pipeline uses two-period average GDP from predictors_master.json — each country gets one number across the whole panel. The repro script uses game-level GDP, so a country’s rank could theoretically shift between Sydney 2000 and Paris 2024. For the median split this mostly doesn’t matter (rich countries stay rich), but Estonia going from $5,872 to $49,969 is exactly the kind of case where it could.

Using the game-level GDP is more consistent with the rest of the v0.99 design (year-specific predictors throughout). But it introduces the possibility that a country is “upper” in one game and “lower” in another, which complicates interpretation. A fixed ranking (country-level mean GDP across all games) is cleaner for a subsample split that’s meant to be structural, not time-varying.

2. What sample to compute the median on

The original computes the median on all 71 countries in the regression sample. The repro computes it only on countries with positive points in the relevant subset. This is the bigger problem — conditioning the GDP split on the outcome variable (scoring points) is methodologically suspect. It means the “upper half” is defined partly by Olympic success, which is what we’re trying to explain.

3. Threshold: > vs >=

The original uses > median (35 upper), the repro uses >= median (36 upper). With 71 countries, one country sits exactly at the median. This is minor but should be documented.

My recommendation for the paper:

The cleanest approach is: compute each country’s mean GDP across all games in the panel, rank the 71 countries once, split at the median (define whether the median country goes up or down — conventionally >= gives the upper half), and use that fixed split throughout. This should be stated explicitly in Section 2 or 4, something like: “Countries are classified as upper-GDP if their mean GDP per capita across the seven games exceeds the sample median of [X]. This classification is time-invariant: [N] countries are upper-GDP throughout the panel.”

The time-invariant split is defensible because the subsample analysis isn’t about GDP dynamics — it’s about whether the cost gradient concentrates among richer countries. A country’s structural wealth level matters more than year-to-year fluctuation.

What’s your view — fixed country-level mean, or should the split be allowed to vary by game?

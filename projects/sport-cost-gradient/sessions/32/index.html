Current model:

The preference function w(y,c) is integrated over the Dagum distribution to get an aggregate participation score. This enters performance roughly linearly. So doubling the affordable population doubles the contribution.

The problem with linearity:

Talent is rare. If 80% vs 40% of the population can afford a sport, the linear model says 2× advantage. But extreme value theory says the advantage is much less than 2× for finding one Olympic medallist — you already had a deep pool at 40%.

Conversely, going from 5% to 10% is huge — you’ve doubled your chance of finding a once-in-a-generation talent.

Proposed fix:

Replace the linear aggregation with a concave function:

performance_contribution = (effective_pool)^η

where η < 1. This is one new parameter. When η = 1 we recover the current model. When η → 0, only the extensive margin matters.

Why this helps the Gini gradient:

With concavity, unequal countries (small affordable pool for expensive sports) sit on the steep part of the curve. Equal countries (large pool) sit on the flat part. The difference between them is amplified compared to the linear case — exactly what we need to close the 63% gap.

The theoretical backing is extreme value statistics: expected maximum of n i.i.d. draws from a normal distribution grows as √(2 ln n), which is strongly concave.

    • LS decomposition: 5-target weighted objective: ln_gdp, ln_pop, n (cells), Gini×equip (3× weight), ln_lag. Showed persistence inflation is the main penalty for strong-Gini entries.
    • Autocorrelation diagnostic: Empirical between-Games autocorrelation = 0.83. Winner sim = 0.88. High-gamma #987 = 0.96. Proved the simulation becomes too deterministic.
    • Between-Games quality noise: quality += rng.normal(0, noise_sd, size=quality.shape) added after L1/L2/L3 computation, before tournament. Fixes persistence but creates cell-killing at high noise_sd.
    • Noise-cell relationship: More noise genuinely reduces cells (confirmed with controlled experiment). Cell count peaks at noise_sd ≈ 1.0, drops above. Sweet spot: 1.0–1.5.
    • CMA-ES (Covariance Matrix Adaptation Evolution Strategy): Derivative-free local optimizer. 5-seed averaging per evaluation. Hard constraints via penalty function (PENALTY=20.0).
    • Gumbel tournament: quality → Gumbel(loc=q, scale=sigma) → 3 athletes per country → max → top 6 score. Sigma constant across countries. n_athletes hardcoded to 3.
    • Simulation chain: Dagum income → continuous preference w(y,c) → weights → N_alloc → N_drain → q=alpha×log(N_drain) → L2 GDP quality → L3 persistence → noise → Gumbel tournament → points

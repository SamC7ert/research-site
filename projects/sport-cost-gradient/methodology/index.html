Simulation Calibration Methodology

Full specification of the microsimulation model, calibration procedure, and model comparison framework.

Motivation#

The simulation models the talent pipeline from population to quality distribution through affordability filtering (Layer 1), GDP-linked training quality (Layer 2), and game-to-game persistence via experience points (Layer 3). The central empirical question is whether these mechanisms can jointly reproduce the patterns observed in the data — specifically, the Gini x ln(equipment cost) interaction gradient, the GDP-performance relationship, and the persistence effect — or whether the observed Gini x cost gradient requires mechanisms beyond those we have modelled.

This is not a curve-fitting exercise. It is a test of theoretical sufficiency. The empirical regression coefficients are the observations; the simulation is the proposed theory. We ask: does this theory, with its mechanistic structure, have the capacity to produce these observations under any parameterisation? If it does, the model is sufficient. If it does not, we have established the limits of the model and quantified what fraction of the observed patterns it can explain.

Target Observations#

The calibration targets are the regression coefficients from the paper’s primary specification, estimated on empirical data. The regression specification applied to simulated data is identical to the one applied to empirical data: OLS with HC1 robust standard errors, sport and game fixed effects, Soviet dummy, religion controls, and the points > 0 filter. (Note: the simulation evaluation uses HC1 rather than country-clustered standard errors, since calibration targets are point estimates — the choice of variance estimator does not affect the betas.)

We organise the target coefficients into two tiers reflecting our confidence in the underlying mechanisms.

Tier 1: Anchoring Targets (must match)#

These coefficients reflect mechanisms we are confident exist and that the model must reproduce to be credible:

Target Specification Mechanism
ln(lag) ind, upper GDP, with lag Game-to-game persistence
ln(GDP) ind, upper GDP GDP -> performance (quality + allocation)
ln(Pop) ind, upper GDP Population scale -> talent pool
ln(GDP) ind, all countries GDP effect across full sample
ln(Pop) ind, all countries Population effect across full sample
ln(GDP) all sports, all countries GDP effect in broadest specification
ln(Pop) all sports, all countries Population effect in broadest specification

These seven targets anchor the simulation’s macrostructure. A simulation that gets these wrong is not a credible representation of Olympic performance, regardless of what it says about inequality.

Tier 2: The Question (Gini x equipment cost interaction)#

These coefficients are what we seek to explain:

Target Specification
Gini x ln(equip) ind, upper GDP
Gini x ln(equip) ind, all countries
Gini x ln(equip) all sports, all countries
Gini x ln(equip) ind, upper GDP, with lag

The Tier 2 targets are not constraints — they are the dependent variable of the exercise. The question is: within the region of parameter space where Tier 1 targets are satisfied, what is the strongest Gini x ln(equip) gradient the model can achieve?

Model Architecture#

Stage 1: Affordability Filtering and Allocation#

For each country-sport-period cell, compute the participant pool. The simulation begins by identifying the share of the youth population that can afford each sport, using a Dagum income distribution parameterised from GDP and Gini.

The Dagum distribution captures heavy-tailed upper incomes characteristic of unequal societies more accurately than the lognormal. It is parameterised as:

a = 1 / (gini / 100)          (shape parameter from Gini)
b = gdp / M(a)                (scale parameter, where M(a) is the Dagum mean factor)

The mean factor M(a) ensures that the distribution’s mean equals GDP per capita:

M(a) = Gamma(1 + 1/a) * Gamma(1 - 1/a) / Gamma(1)   for a > 1

A household’s effective cost threshold combines a subsistence floor and sport equipment cost:

T_min = S + R_eff * c_min

where S is the subsistence parameter, R_eff = R / disc_share (R is the cost ratio, disc_share is the fraction of household income available for sport), and c_min is the cheapest sport’s equipment cost. Households whose income falls below T_min are excluded from the talent pool. The survival fraction is:

survival = 1 / (1 + (T_min / b)^a)

The base participant pool is:

N_part = Y * pi_c * survival

where Y = population * YOUTH_SHARE (0.30), and pi_c is the cultural participation factor (reduced by religion penalty).

For each sport, a continuous affordability preference is computed from the Dagum survival function at that sport’s cost level, combined with infrastructure access, popularity feedback from previous games, and wealth skewness:

weight_s = affordability_s * infrastructure_s * popularity_s * wealth_factor_s

Sport weights are normalised across all sports for each country-period. The effective athlete count is:

N_eff = N_part * normalised_weight * (1 - drain)

where drain is the fraction of talent lost to non-Olympic sports (cricket, American football, etc.).

Quality from talent pool size follows an extreme-value elasticity:

q_L1 = alpha * ln(N_eff)

Infrastructure access uses a logistic function of GDP relative to facility cost:

infrastructure = 1 / (1 + exp(-kappa * (gdp / (tau * facility_cost) - 1)))

Stage 2: GDP Quality Adjustment#

A GDP-mediated training channel adds quality for countries that can fund expensive training:

q_L2 = q_L1 + beta * ln(gdp) * ln(non_equip_cost)

where non_equip_cost = coaching + competition + facility access (everything except household equipment cost).

Stage 3: Experience-Based Persistence#

For the game-by-game simulation (1984 -> 2024), a persistence term is added based on experience points from previous games:

q_L3 = q_L2 + gamma * ln(1 + exp_{t-1}) + LAG2_DECAY * gamma * ln(1 + exp_{t-2})

where LAG2_DECAY = 0.68 (fixed from the empirical lag2/lag1 ratio).

Experience points are derived from the top 40 positions in each simulated game, using a biathlon-style scoring system (IBU World Cup points: 90, 75, 60, 50, 45, 40, … down to 1 for rank 40). Relying only on the simulated top-six finishers for feedback would concentrate results excessively, so the lag operates on this broader experience measure. Scoring for the regression (the dependent variable) remains top-6 only, using the 6-5-4-3-2-1 scale.

The simulation is seeded with empirical results for 1984-1992. From 1996 onward, the simulation generates its own results and feeds them forward.

Stage 4: Competition#

Each country sends 3 athletes per event. Performance is drawn from a Gumbel extreme-value distribution:

performance = quality + sigma * Gumbel(0, 1)

Between-games noise is added to quality before the tournament:

quality += Normal(0, noise_sd)

Top 6 across all countries score 6-5-4-3-2-1 per event. Top 40 positions generate experience points for the persistence mechanism. Points are aggregated across events per sport, then across sports per country. 100 Monte Carlo runs are averaged for stability in the final evaluation.

Free Parameters#

The model has 9 free parameters optimised during calibration:

Parameter Symbol Description
Persistence strength gamma Weight on lagged experience
Tournament noise sigma Gumbel scale in competition
GDP quality beta GDP x non-equip cost interaction
Talent pool elasticity alpha Extreme-value elasticity on pool size
Subsistence floor S Minimum income before sport spending
Cost ratio R Equipment cost multiplier for threshold
Wealth skewness delta Extra weight for rich countries in expensive sports
Between-games noise noise_sd Quality noise across simulation runs
Discretionary share disc_share Fraction of household income available for sport

Fixed structural parameters include infrastructure sensitivity (kappa = 5.0), infrastructure threshold (tau = 50.0), football popularity weight (5.0), popularity feedback (0.5), religion weights, host bonus (1.0), athletes per event (3), and lag2 decay ratio (0.68).

Calibration Procedure#

Phase A: Latin Hypercube Exploration#

500-point Latin Hypercube Sampling across the 9 free parameters identifies promising regions of parameter space. Each sample point is evaluated with 10 simulation seeds. Points are scored by a weighted loss function combining Tier 1 and Tier 2 target deviations, with the Gini x ln(equip) target weighted 3x.

Phase B: CMA-ES Optimisation#

The Covariance Matrix Adaptation Evolution Strategy (CMA-ES) refines the best candidates from Phase A. CMA-ES is a derivative-free optimiser well-suited to noisy objective functions. Three optimisation modes are run:

  • Mode 1: Minimise loss function (balanced improvement)
  • Mode 2: Maximise Gini gradient strength (keep loss below starting value)
  • Mode 3: Minimise loss (keep Gini gradient at least as strong as starting value)

Mode 3 consistently produces the best candidates — it prevents the optimiser from trading Gini gradient strength for better fit on other targets.

Multiple rounds of CMA-ES are run with progressively adjusted parameter bounds as bound-hitting patterns emerge. Each generation’s results are saved incrementally.

Phase C: 100-Seed Validation#

The best CMA-ES candidates are validated with 100 independent simulation seeds to ensure stability and guard against flukes from the 10-seed CMA evaluation. Per-seed statistics (mean, SD, SE, 95% CI) are computed for all targets.

Best Candidate (v1.05)#

The final parameter set (CMA-ES round 2, mode 3, generation 11) evaluated across 100 seeds:

Metric Simulated Empirical Error
Gini x ln(equip), with lag -0.50 -0.68 26%
ln(GDP) 5.53 5.19 7%
ln(Pop) 0.74 0.94 -21%
ln(lag1) 5.01 4.20 19%
N (observations) 1650 1998 -17%

The simulation reproduces 74% of the empirical Gini x equipment cost gradient. All 100 seeds produce a negative gradient (p = 0.01). Gradient decomposition shows the simulation matches the empirical gradient almost exactly when the United States is excluded (simulated -0.19 vs empirical -0.22, gap 0.03).

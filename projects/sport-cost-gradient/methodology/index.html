Simulation Calibration Methodology

Full specification of the microsimulation model, calibration procedure, and model comparison framework.

Motivation#

The simulation models the talent pipeline from population to quality distribution through allocation mechanics (Layer 1), GDP-linked training quality (Layer 2), and game-to-game persistence (Layer 3). The central empirical question is whether these mechanisms can jointly reproduce the patterns observed in the data — specifically, the Gini × ln(equipment cost) interaction gradient, the GDP–performance relationship, and the persistence effect — or whether the observed Gini × cost gradient requires mechanisms beyond those we have modelled.

This is not a curve-fitting exercise. It is a test of theoretical sufficiency. The empirical regression coefficients are the observations; the simulation is the proposed theory. We ask: does this theory, with its mechanistic structure, have the capacity to produce these observations under any parameterisation? If it does, the model is sufficient. If it does not, we have established the limits of the model and quantified what fraction of the observed patterns it can explain.

Target Observations#

The calibration targets are the regression coefficients from the paper’s primary specification, estimated on empirical data. The regression specification applied to simulated data is identical to the one applied to empirical data: OLS with HC1 robust standard errors, sport and game fixed effects, Soviet dummy, religion controls, and the points > 0 filter. (Note: the simulation evaluation uses HC1 rather than country-clustered standard errors, since calibration targets are point estimates — the choice of variance estimator does not affect the betas.)

We organise the target coefficients into two tiers reflecting our confidence in the underlying mechanisms.

Tier 1: Anchoring Targets (must match)#

These coefficients reflect mechanisms we are confident exist and that the model must reproduce to be credible:

Target Specification Mechanism
ln(lag) ind, upper GDP, with lag Game-to-game persistence
ln(GDP) ind, upper GDP GDP → performance (quality + allocation)
ln(Pop) ind, upper GDP Population scale → talent pool
ln(GDP) ind, all countries GDP effect across full sample
ln(Pop) ind, all countries Population effect across full sample
ln(GDP) all sports, all countries GDP effect in broadest specification
ln(Pop) all sports, all countries Population effect in broadest specification

These seven targets anchor the simulation’s macrostructure. A simulation that gets these wrong is not a credible representation of Olympic performance, regardless of what it says about inequality.

Tier 2: The Question (Gini × equipment cost interaction)#

These coefficients are what we seek to explain:

Target Specification
Gini × ln(equip) ind, upper GDP
Gini × ln(equip) ind, all countries
Gini × ln(equip) all sports, all countries
Gini × ln(equip) ind, upper GDP, with lag

The Tier 2 targets are not constraints — they are the dependent variable of the exercise. The question is: within the region of parameter space where Tier 1 targets are satisfied, what is the strongest Gini × ln(equip) gradient the model can achieve?

Model Architecture#

Stage 1: Allocation#

For each country-sport-period cell, compute the expected athlete pool:

raw_pool = population × YOUTH_SHARE
pool_alpha = raw_pool ^ ALPHA                          (population elasticity)
affordability = 1 - Φ((ln(min_income) - μ) / σ)       (lognormal CDF)
    where min_income = SUB + equip_cost × RATIO
    μ = ln(gdp_pc) - (gini/100)²
    σ = gini / 100
infrastructure = 1 / (1 + exp(-INFRA_SENS × (gdp_pc / (THRESHOLD × infra_cost_M) - 1)))
sport_weight = affordability × infrastructure × popularity_weight

Sport weights are normalised across all sports for each country-period. The effective athlete count is:

N_eff = pool_alpha × sport_weight × (1 - drain) × (1 - religion_penalty)

Where drain is the fraction of talent lost to non-Olympic sports (cricket, American football, etc.), and religion_penalty captures systematic underperformance:

religion_penalty = min(0.5, REL_WEIGHT_MUSLIM × pct_muslim
                            + REL_WEIGHT_HINDU × pct_hindu
                            + REL_WEIGHT_BUDDHIST × pct_buddhist)

Stage 2: Competition#

For each sport-period, compute competitive quality per country:

quality = ln(N_eff) + BETA × ln(gdp_pc) × ln(non_equip_cost) + HOST_BONUS × is_host

Where non_equip_cost = coaching + competition + facility_access (everything except household equipment).

Each country sends 3 athletes per event. Performance is drawn from a t-distribution:

performance = quality + SIGMA × t(df=DF_T)

Top 6 across all countries score 6-5-4-3-2-1 per event. Points aggregated across events per sport, then across sports per country. Multiple Monte Carlo runs averaged for stability.

Stage 3: Persistence#

For the game-by-game simulation (Sydney 2000 → Paris 2024), a persistence term is added:

quality += γ × ln(1 + previous_points_in_same_sport)

Three configurations to test:

  • Cultural: Seed = Sydney 2000 empirical results, frozen for all subsequent games.
  • Rolling: Seed = previous game’s empirical results, updated each game.
  • Combined: Both terms with separate γ values.

Calibration Procedure#

The calibration is structured in three phases, each building on the previous.

Phase A: Anchor the Macrostructure#

Purpose: Find the region of parameter space where the model reproduces persistence, GDP, and population effects.

Method: Latin Hypercube Sampling across 500 points in the four parameters that directly control the Tier 1 targets:

Parameter Range Controls
γ (persistence) [0.3, 4.0] ln(lag) coefficient
σ (tournament noise) [0.15, 0.55] All coefficient magnitudes (signal-to-noise)
β (GDP quality) [0.005, 0.06] ln(GDP) coefficient
α (extreme value elasticity) [0.25, 0.60] ln(Pop) coefficient and overall scale

All other parameters are held at structurally motivated defaults. Each sample point is evaluated with a single simulation run. The feasible region is defined as all parameter combinations where every Tier 1 target is within ±30% of its empirical value.

Phase B: Maximise the Gini × Cost Gradient#

Purpose: Within the anchor region from Phase A, sweep the remaining allocation parameters to find the strongest achievable Gini × ln(equip) gradient.

Method: Take the top 5 anchor parameter sets from Phase A. For each, run 300 Latin Hypercube samples across 9 allocation parameters:

Parameter Range Role
wealth_skew (δ) [0.0, 0.5] Most direct Gini × cost lever
alpha (α) [0.30, 0.55] Extreme value elasticity
pi0 (π₀) [0.005, 0.06] Base participation rate
lam (λ) [0.3, 1.5] Religion scale
subsistence (S) [1000, 12000] Affordability threshold
cost_ratio (R) [2, 20] Cost multiplier
beta (β) [0.02, 0.08] GDP quality strength
pop_feedback (ψ) [0.1, 2.0] Popularity feedback
football_pop (φ_F) [2, 12] Football popularity

This produces 1,500 parameter states (5 anchors × 300 samples), each evaluated with a single simulation. Results are ranked by a combined objective that penalises Tier 1 violations while prioritising Tier 2 closeness.

Phase C: Evaluation with Confidence Intervals#

Purpose: Produce publication-quality estimates at the best parameter states.

Method: Take the top 5 parameter sets from Phase B. Run 20 independent simulations each (different random seeds). Report mean, standard deviation, and 95% confidence intervals for all target coefficients.

Model Comparison#

The calibration is conducted for three model specifications:

Model A — Allocation only (Layer 1):

$$q_{c,s,g} = \alpha \cdot \ln(N_{c,s,g}^{\text{drain}})$$

Model B — Allocation + GDP quality (Layers 1+2):

$$q_{c,s,g} = \alpha \cdot \ln(N_{c,s,g}^{\text{drain}}) + \beta \cdot \ln(\text{GDP}_c) \cdot \ln(\text{non-equip}_s)$$

Model C — Full model (Layers 1+2+3):

$$q_{c,s,g} = \alpha \cdot \ln(N_{c,s,g}^{\text{drain}}) + \beta \cdot \ln(\text{GDP}_c) \cdot \ln(\text{non-equip}s) + \gamma \cdot \ln(1 + \text{pts}{c,s,g-1})$$

Pareto Surface Analysis#

With multiple target moments, there is no single “best” parameterisation unless the model can match all targets simultaneously. The calibration maps the Pareto frontier — the set of parameterisations where no target can be improved without worsening another.

If the empirical observation vector lies inside the Pareto surface, the model is sufficient. If it lies outside, the model faces structural trade-offs. The shape of the frontier reveals the nature of the deficiency.
